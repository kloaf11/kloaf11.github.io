## Introduction

### Software Engineering/Design

I will take my zoo monitoring program from IT-145 and use it for the software engineering and design category. Right now, the code uses rudimentary files and offers few ways to check on the animals and habitats. I will enhance the program with data files for more animals and habitats, an employee section, a zoo transfer system, and a code structure that is more modular and efficient.

### Category Two: Algorithms and Data Structures

I will work with the same artifact as above, my zoo monitoring program from IT-145. For this category, I will use a more robust structure for reading the stored data. Currently it uses only .txt files and reads them line by line for the output. For this step I will add more data per file and retrieve data from a SQL database instead of a text file based on guesses about the file and the amounts. The output will also vary based on the data in the result set, instead of showing all of the data and reacting to rudimentary call signs. This part also ties into the next part of the enhancements.

### Category Three: Databases

This artifact will, in theory, be made from scratch, but you can consider it an improvement on the data held in the zoo monitoring program, which at the start of this project was mere text files. I will create a SQL Server database with Microsoft SQL Server, and I will create the relational databases for the zoo monitoring program to access. Each object type will be a table that the program reads and returns as a result set.
